# Herramientas sobre DNS

- [WhatIsMyIPAddress](https://whatismyipaddress.com): Te permite administrar tu DNS, encontrar tu IP, y mucho más.
- [Zoho Toolkit](https://www.zoho.com/toolkit/dns-a-record.html): Es una herramienta para hacer pruebas de DNS, sirve para monitorear registros DNS.
- [DNSstuff](https://www.dnsstuff.com): Herramienta para hacer pruebas de DNS, monitorear registros DNS, y más.
- [Google Toolbox Dig](https://toolbox.googleapps.com/apps/dig/): Herramienta de Google para hacer pruebas de DNS.
- [Check Host Net](https://check-host.net/check-dns): Herramienta para hacer pruebas de DNS en varios servidores.
- [IntoDNS](https://intodns.com/check): Herramienta para validar la configuración de tu DNS.
- [DNS Lookup](https://www.nslookup.io/domains): Herramienta para hacer pruebas de DNS, valida registros SPF, TXT y Nameservers.
- [DNS Checker](https://dnschecker.org): Herramienta para hacer pruebas de DNS, valida registros SPF, TXT y Nameservers en varios servidores.
- [MXToolBox](https://mxtoolbox.com/SuperTool.aspx): Es una de las herramientas más completas para hacer pruebas de DNS, monitorear registros DNS, y más.
- [What's My DNS](https://www.whatsmydns.net): Herramienta para hacer pruebas de DNS, valida registros SPF, TXT y Nameservers en varios servidores.
- [DNS Watch](https://dns.watch): Herramienta para hacer pruebas de DNS, valida registros SPF, TXT y Nameservers en varios servidores.
- [DNSViz](http://dnsviz.net): Herramienta para hacer pruebas de DNS, valida registros SPF, TXT y Nameservers en varios servidores.
- [DNSChecker](https://dnschecker.org): Herramienta para hacer pruebas de DNS, valida registros SPF, TXT y Nameservers en varios servidores.
- [DNSQuery](https://dnsquery.org): Herramienta para hacer pruebas de DNS, valida registros SPF, TXT y Nameservers en varios servidores.
